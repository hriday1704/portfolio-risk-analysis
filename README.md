# Portfolio Risk Analysis & Diversification Modelling

This project performs portfolio risk analysis and diversification modelling on a multi-asset Indian equity portfolio using Python and real market data from Yahoo Finance.

The project analyzes portfolio volatility, correlations between assets, diversification effects, and downside risk using Value-at-Risk (VaR) metrics.

---

## Features

- Multi-asset Indian equity portfolio construction
- Daily return calculation using historical stock prices
- Individual stock volatility analysis
- Correlation matrix computation
- Portfolio volatility estimation
- Annualised volatility calculation
- Historical Value-at-Risk (VaR) at 95% and 99% confidence levels
- Portfolio return distribution visualization

## Risk Analytics Implemented

### Portfolio Volatility
Calculated portfolio standard deviation using weighted portfolio returns.

### Correlation Analysis
Measured relationships between asset returns to evaluate diversification benefits.

### Historical Value-at-Risk (VaR)
Estimated downside portfolio risk using historical simulation at:

- 95% confidence level
- 99% confidence level

### Annualised Volatility
Converted daily volatility into annualized risk metrics using:

σannual = σdaily × √252
